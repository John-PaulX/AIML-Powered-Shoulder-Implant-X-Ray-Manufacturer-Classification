# Shoulder Implant X-Ray Manufacturer Classification

## Project Overview

This project uses Machine Learning to classify shoulder implant X-ray images into different manufacturer categories. The model analyzes implant patterns from X-ray images and predicts the manufacturer class.

This project was developed as part of research in medical image analysis and orthopedic implant classification.

---

## Problem Statement

Identifying the manufacturer of shoulder implants from X-ray images manually can be time-consuming and may require expert analysis. This project automates that process using machine learning techniques.

---

## Manufacturers Classified

The model classifies implants into the following manufacturers:

- Cofield
- Depuy
- Tornier
- Zimmer
